Privacy Policy

Last updated: May 2026

Sidefold is a Chrome extension: Organize Subscriptions for YouTube™. This page explains what data the extension accesses and how it is handled.
Short version: Your categories stay local by default. If you sign in with Google (optional), your categories sync to Supabase; only your email and categories are stored. We don't track viewing habits, sell data, or share it with third parties.

1. Data Storage: Local vs. Cloud

By default (no sign-in): All data stays on your device. No data sent to any server.

With cloud sync enabled (optional): Starting with Sidefold 1.2.0, you can optionally sign in with your Google account to sync categories and assignments across your devices. This is completely optional — the extension works offline without an account.

2. Local Storage (Always)

The extension stores the following data exclusively within your browser using Chrome's built-in storage API (chrome.storage):

  • Folder names, colors, and order you create.
  • Assignments between YouTube channel IDs and your folders.
  • Extension preferences (layout, display options).
  • A cached list of your YouTube subscriptions (channel names and avatars), stored locally to avoid repeated network requests.

3. Cloud Sync Data (Optional, v1.2.0+)

If you sign in with Google, the following data is transmitted to Supabase (our cloud backend) and stored server-side:

  • Your Google email address and unique user ID (used for authentication only)
  • Your category data (names, colors, order)
  • Your channel assignments (which channels belong to which categories)
  • Timestamps of last updates (used for conflict resolution)

Data protection:

  • All data is transmitted over HTTPS (encrypted in transit)
  • Supabase uses Row Level Security (RLS): only you can access your own data
  • We do not encrypt data at rest (Supabase is managed; security is delegated to them)
  • Data is retained as long as your account exists; you can delete it by signing out

4. Data We Do Not Collect

  • No watch history, viewing habits, or YouTube activity.
  • No browsing data outside of YouTube.
  • No cookies (the extension does not set or read any cookies).
  • No analytics, crash reports, or third-party tracking services.

5. Data Usage

  • Email: Used only to verify your identity via Google OAuth. Not used for marketing or sharing.
  • Categories & assignments: Used only for syncing across your devices. Never shared, sold, or used for any other purpose.
  • Timestamps: Used internally to resolve conflicts (last-write-wins) when you edit on multiple devices simultaneously.

6. YouTube Access

The extension reads your YouTube subscription list by fetching youtube.com/feed/channels using your existing YouTube session in the browser. This data is used only to display your channels inside the extension UI and is never transmitted to our servers (Supabase receives only the categories and assignments you create).

7. Third-Party Services

The extension uses Supabase (https://supabase.com) for cloud storage if you enable sync. Supabase is a PostgreSQL-based backend with Google Cloud infrastructure. By signing in, you agree to their privacy policy.

Google OAuth is used for authentication; your Google account terms apply separately.

6. Open Source

The extension's source code is publicly available under the MIT license at the GitHub repository. You can audit exactly what the extension does.

7. Changes to This Policy

If this policy changes, the updated version will be published at this URL with a new "Last updated" date.

8. Contact

For questions or concerns, please open an issue in the GitHub issue tracker.

Política de privacidad

Última actualización: mayo de 2026

Sidefold es una extensión de Chrome: Organize Subscriptions for YouTube™. Esta página explica qué datos accede la extensión y cómo se gestionan.
Resumen: Tus categorías se guardan localmente por defecto. Si inicias sesión con Google (opcional), tus categorías se sincronizan a Supabase; solo se almacenan tu correo electrónico y tus categorías. No rastreamos hábitos de visualización, no vendemos datos ni los compartimos con terceros.

1. Almacenamiento de datos: Local vs. Nube

Por defecto (sin iniciar sesión): Todos los datos se guardan en tu dispositivo. Ningún dato se envía a ningún servidor.

Con sincronización en la nube activada (opcional): A partir de Sidefold 1.2.0, puedes opcionalmente iniciar sesión con tu cuenta de Google para sincronizar categorías y asignaciones entre tus dispositivos. Esto es completamente opcional: la extensión funciona sin conexión sin una cuenta.

2. Almacenamiento local (Siempre)

La extensión guarda los siguientes datos exclusivamente en tu navegador, usando la API de almacenamiento integrada de Chrome (chrome.storage):

  • Nombres, colores y orden de las carpetas que creas.
  • Asignaciones entre IDs de canales de YouTube y tus carpetas.
  • Preferencias de la extensión (diseño, opciones de visualización).
  • Una caché de tu lista de suscripciones de YouTube (nombres de canales y avatares), guardada localmente para evitar peticiones repetidas.

3. Datos de sincronización en la nube (Opcional, v1.2.0+)

Si inicias sesión con Google, los siguientes datos se transmiten a Supabase (nuestro servidor en la nube) y se almacenan en el servidor:

  • Tu correo electrónico de Google e ID de usuario único (usado solo para autenticación)
  • Tus datos de categorías (nombres, colores, orden)
  • Tus asignaciones de canales (qué canales pertenecen a qué categorías)
  • Marcas de tiempo de últimas actualizaciones (usadas para resolución de conflictos)

Protección de datos:

  • Todos los datos se transmiten por HTTPS (cifrados en tránsito)
  • Supabase usa Row Level Security (RLS): solo tú puedes acceder a tus datos
  • No ciframos los datos en reposo (Supabase es administrado; la seguridad se delega a ellos)
  • Los datos se retienen mientras tu cuenta exista; puedes eliminarlos cerrando sesión

4. Datos que no recopilamos

  • No historial de visualización ni hábitos de visionado.
  • No datos de navegación fuera de YouTube.
  • No cookies (la extensión no establece ni lee ninguna cookie).
  • No analíticas, reportes de errores ni servicios de rastreo de terceros.

5. Uso de datos

  • Correo electrónico: Se usa únicamente para verificar tu identidad vía Google OAuth. No se utiliza para marketing ni compartición.
  • Categorías y asignaciones: Se usan únicamente para sincronizar entre tus dispositivos. Nunca se comparten, venden ni se usan para ningún otro propósito.
  • Marcas de tiempo: Se usan internamente para resolver conflictos (última escritura gana) cuando editas en varios dispositivos simultáneamente.

6. Acceso a YouTube

La extensión lee tu lista de suscripciones de YouTube accediendo a youtube.com/feed/channels con tu sesión activa de YouTube en el navegador. Estos datos se usan únicamente para mostrar tus canales dentro de la interfaz de la extensión y nunca se transmiten a nuestros servidores (Supabase solo recibe las categorías y asignaciones que creas).

7. Servicios de terceros

La extensión usa Supabase (https://supabase.com) para almacenamiento en la nube si activas la sincronización. Supabase es un servidor PostgreSQL con infraestructura de Google Cloud. Al iniciar sesión, aceptas su política de privacidad.

Se utiliza Google OAuth para autenticación; tus términos de cuenta de Google se aplican por separado.

6. Código abierto

El código fuente de la extensión está disponible públicamente bajo licencia MIT en el repositorio de GitHub. Puedes auditar exactamente qué hace la extensión.

7. Cambios en esta política

Si esta política cambia, la versión actualizada se publicará en esta URL con una nueva fecha de "Última actualización".

8. Contacto

Para preguntas o dudas, abre un issue en el issue tracker de GitHub.
